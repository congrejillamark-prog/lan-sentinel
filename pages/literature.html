Research Foundation

Review of Related Literature

This section presents foreign and local studies related to network security, intrusion detection, traffic anomaly analysis, and artificial intelligence.

Foreign Literature

Chandola, Banerjee, and Kumar (2009)
Anomaly Detection: A Survey

This study provides an overview of anomaly detection techniques and explains how unusual patterns can be identified from normal data. It supports the use of anomaly detection in recognizing unusual network behavior.

Ring et al. (2019)
Network-Based Intrusion Detection

This research discusses network-based intrusion detection and the datasets used to evaluate security systems. It provides background for developing and testing intrusion detection methods using network traffic data.

Kolias et al. (2016)
Distributed Denial-of-Service Attacks

This study discusses distributed denial-of-service attacks and their effects on network availability. It is relevant to identifying traffic flooding and other suspicious activities that may affect a local network.

Sharafaldin et al. (2018)
CICIDS2017 Dataset

This research introduces the CICIDS2017 dataset, which contains normal network traffic and different types of attacks. It provides a useful reference for evaluating intrusion detection systems.

Ahmad et al. (2021)
Machine Learning for Intrusion Detection

This study is included as related work on the use of machine learning in intrusion detection. It supports the research direction of using intelligent techniques to recognize suspicious network activity.

Liu et al. (2008)
Outlier Detection

This research discusses methods for identifying unusual data patterns. Its concepts are relevant to detecting network activities that differ from established normal behavior.

Mirsky et al. (2018)
Kitsune: An Ensemble of Autoencoders

This study presents Kitsune, a network intrusion detection system that uses an ensemble of autoencoders to identify unusual network traffic. It demonstrates how machine learning can be applied to network anomaly detection.

Doriguzzi-Corin et al. (2020)
LUCID: A Practical Lightweight Deep Learning Solution

This research presents a lightweight deep learning approach for network intrusion detection. It is relevant to developing detection methods that consider processing efficiency and practical network environments.

Local Literature

Natonton (2018)
Local Network Security Research

This local study is included in the research as related literature concerning network security and the challenges of protecting computer networks. It provides a local perspective for understanding the need for improved network protection.

De Ramos and Esponilla (2022)
Network Security and Intrusion Detection

This study contributes to the local research background on network security. It is relevant to understanding the importance of monitoring network activities and identifying possible security threats.

Aquino and Noroña (2021)
Network Monitoring and Security

This local reference supports the discussion of network monitoring and the need to improve security practices in computer network environments.

Miranda, Tayag, and Canlas (2025)
Related Research on Network Security

This recent local reference contributes to the discussion of network security and the use of technology to address possible threats in computer networks.

Synthesis of Related Literature

The reviewed foreign and local literature shows that network security is important in protecting computer networks from unauthorized access and malicious activities. Previous studies explain how anomaly detection, machine learning, and network traffic analysis can help identify suspicious behavior. Research involving datasets such as CICIDS2017 and systems such as Kitsune and LUCID also demonstrates the use of intelligent techniques in detecting network attacks.

These studies provide a foundation for the development of LAN Sentinel. By using traffic anomaly analysis, the proposed system aims to recognize unusual network behavior and present security alerts through an administrator dashboard.

Identified Research Gap

Although previous studies have explored anomaly detection, machine learning, and network intrusion detection, there remains a need for a practical and accessible solution focused on small-to-medium Local Area Networks, particularly in the Philippine setting.

Existing security tools may depend on predefined rules or previously identified attack patterns. This creates a need for an approach that can establish normal network behavior and identify unusual activities through traffic anomaly analysis.

This research addresses the identified gap by proposing an AI-based Network Intrusion Detection System that analyzes network traffic, detects suspicious activities, and presents alerts and monitoring information through an administrator dashboard.
