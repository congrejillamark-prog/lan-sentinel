Detection Method

Rule-based inspection

Checks observable patterns such as many distinct destination ports, high TCP SYN rates, and conflicting ARP IP-to-MAC mappings.

Optional machine learning

A compatible trained model can be loaded locally. Without it, the dashboard reports rules-only analysis. Demo findings are generated from synthetic records and are never presented as verified detections.
